# Sorting Algorithms

Sorting algorithms arrange elements into a chosen order.

Sorting algorithms can be divided broadly into:

- **Comparison-based sorting:** Bubble Sort, Insertion Sort, Selection Sort,
  Merge Sort, Quick Sort, and Heap Sort.
- **Non-comparison-based sorting:** Counting Sort.

## Properties used for comparison

- Time Complexity
- Space Complexity
- Stability
- In-place behavior
